# Skills — índice

> **Progressive disclosure nivel 1.** Léelo primero para elegir el skill. Abre el `SKILL.md` completo solo del que matchee la tarea. No abras `references/` por defecto. Si dos skills podrían aplicar, lee ambos — están diseñados para encadenarse.
> Formato de cada skill: `skills/_standards/SKILL-format.md`.

| Skill | Cuándo cargarlo | Sub-proceso |
|-------|-----------------|-------------|
| [fundacion-etapa-0](fundacion-etapa-0/SKILL.md) | Poblar la fundación de un producto recién instanciado (entrevista guiada de Etapa 0) | Etapa 0 |
| [ost-facilitator](ost-facilitator/SKILL.md) | Crear, actualizar, revisar o priorizar el Opportunity Solution Tree | Shape |
| [interview-snapshot](interview-snapshot/SKILL.md) | Documentar transcripciones de entrevistas en formato snapshot | Shape |
| [brief-entrevista](brief-entrevista/SKILL.md) | Diseñar una guía de entrevista para nodos del OST con gaps de evidencia | Shape |
| [ideacion-estructurada](ideacion-estructurada/SKILL.md) | Generar y preseleccionar candidatas de solución para la oportunidad target | Ideate |
| [assumption-testing](assumption-testing/SKILL.md) | Mapear supuestos de una candidata, rankearlos por riesgo y diseñar su test más barato | Validate |
| [brief-test-no-moderado](brief-test-no-moderado/SKILL.md) | Diseñar un test no moderado (Lyssna u otra) para validar comprensión o usabilidad | Validate |
| [redactar-prd](redactar-prd/SKILL.md) | Madurar el brief seleccionado a PRD Maestro / PRD de feature / Iteration PRDs dev-ready | Handoff |
| [disenar-experimento](disenar-experimento/SKILL.md) | Diseñar la validación post-build (A/B, fake door, rollout) con umbral pre-registrado | Experimentación |
| [decision-ship](decision-ship/SKILL.md) | Leer resultados del experimento y facilitar la decisión ship/no-ship/iterar | Experimentación |
| [bibliotecario-evidencia](bibliotecario-evidencia/SKILL.md) | Procesar el `_inbox` de evidencia: ficha EV-NNN, archivado e índice buscable | Transversal |
| [actualizar-bitacora-humana](actualizar-bitacora-humana/SKILL.md) | Consolidar notas personales del equipo en la bitácora humana | Transversal |
| [cierre-de-ciclo](cierre-de-ciclo/SKILL.md) | Cerrar un ciclo de sub-proceso: retro, archivar, actualizar bitácora | Transversal |
| [generar-presentacion-html](generar-presentacion-html/SKILL.md) | Convertir un artefacto estratégico en HTML ejecutivo para stakeholders | Transversal |

> **Cobertura del pipeline (v2.2, 2026-07-14):** Etapa 0 y los 6 sub-procesos tienen skill — Etapa 0 (1), Shape (3), Ideate (1), Validate (2), Handoff (1), Experimentación (2), transversales (4). Build se orquesta con Speckit en el repo de código (ver ADR-001). Todos invocables también como skill nativo (`.claude/skills/`).
